The Plain-English Jargon Translator

When the senior CSE professor drops fancy technical terms, smile and explain them using these memorable real-world analogies.

1. Idempotency (आयडेमपोटेन्सी)

Security / Ingress

"Like pressing an elevator button multiple times."

No matter how many times you press the button, the elevator only arrives once. If WhatsApp or network retries send the same webhook 3 times, our database checks the message_id and only executes the transaction once.

2. Reverse Math (Voice-to-Scale)

Retail Automation

"The Kirana scale inverted calculator."

Instead of asking customer to buy in fixed grams, customer says ₹20. The system inverts the unit price: (₹20 / ₹42/kg) × 1000 = 476g. The shopkeeper simply places 476 grams on the scale. Takes 0.022ms.

3. Dual-Role Firewall & Zero Direct Deduction

Security Invariant

"The shop counter barrier."

Customers cannot reach behind the counter and take items off the shelf. Similarly, a WhatsApp customer ordering a list cannot decrement inventory. It sits in PENDING on the merchant's screen until the merchant physically packs it.

4. Event Sourcing / Delta Ledger

Accounting & Audit

"Like a bank passbook instead of an eraser."

We never erase or overwrite stock. Every transaction is an immutable line item: (+10 oil, -5 sugar, -2 bread). The current stock is simply the sum of all lines. This allows 1-click Undo without corrupting history.

5. Write-Ahead Logging (WAL Mode)

Storage Concurrency

"Writing on a sticky note before updating the master ledger."

In standard SQLite, writing locks the whole file and blocks readers. With WAL mode (PRAGMA journal_mode=WAL), writers append to a separate journal log, so readers (the dashboard) never get blocked.

6. Sub-50ms Async Webhook Ingress

Network Architecture

"Saying 'Order received!' to the customer, then walking to the kitchen."

Meta drops WhatsApp connections if they take longer than 5 seconds. We return HTTP 200 OK within 42ms, and process the Gemini AI extraction in a background worker task. Zero timeout risk.
